========================================================================
SARS TALENT HOMEPAGE ARCHITECTURE & IMPLEMENTATION GUIDE
========================================================================

OBJECTIVE
---------
To construct a modern, visually stunning, fully responsive, and highly interactive landing page for the SARS TALENT platform. The architecture is built using Next.js 15, React 19, Tailwind CSS v4, and Framer Motion, ensuring smooth animations, high-contrast readability, full keyboard accessibility, WAI-ARIA compliance, and zero layout shifts.


SYSTEM CONNECTION FLOW
======================
[Root Layout: layout.tsx]
       │ (Imports globals.css, sets fonts, Navbar & Footer wrappers)
       ▼
[Home Page: page.tsx]
       │ (Orchestrates all landing page sections in precise order)
       ├─► [Section 1: Hero.tsx] (Futuristic background video, staggered word fade-ins) [Dark]
       ├─► [Section 2: TrustedBy.tsx] (Smooth infinite logo marquee, grayscale hover transition) [Light]
       ├─► [Section 3: ServicesGrid.tsx] (Responsive cards layout with hover lift & blue glow) [Dark]
       ├─► [Section 4: ProcessTimeline.tsx] (Staggered timeline with animated drawing connection lines & traveling dot) [Dark]
       ├─► [Section 5: Comparison.tsx] (Muted traditional vs dark recommended card, pulsing VS badge) [Light]
       ├─► [Section 6: IndustriesMarquee.tsx] (Opposite scrolling pill marquees, light theme glass pills) [Light]
       ├─► [Section 7: Stats.tsx] (Viewport-triggered count-up cards, dark slate metallic gradient) [Dark]
       ├─► [Section 8: Testimonials.tsx] (5-second auto-rotate client success carousel with center card scaling) [Light]
       ├─► [Section 9: FeaturedRoles.tsx] (Interactive job cards, keyboard focusable, whileHover lift & glow) [Light Gray]
       └─► [Section 10: FAQ.tsx] (Smooth height-expanding accordion, plus-to-cross rotation, WAI-ARIA compliant) [White]


FILE-BY-FILE DETAILS (OBJECTIVE, LOGIC & IMPLEMENTATION)
========================================================

1. app/globals.css
   ---------------
   * Objective: Configure global theme styles, custom scrollbars, text selection color, and centralize hardware-accelerated CSS marquee keyframes.
   * Connection: Loaded at the root layout level; styles apply globally to all components.
   * Logic & Implementation Steps:
     a. Configures Tailwind theme parameters (primary blue, navy, black, fonts).
     b. Implements a global `.glass` class for glassmorphic elements.
     c. Defines keyframe animations using `translate3d` to activate GPU rendering for better rendering performance:
        - `marquee-left`: Translates 0% to -50% (right-to-left loop).
        - `marquee-right`: Translates -50% to 0% (left-to-right loop).
     d. Establishes `.marquee-parent` hover play state controls, allowing marquees to pause animation when their container is hovered.
     e. Styles `.marquee-logo` to render in grayscale with 50% opacity by default, transitioning to full color and 100% opacity on hover.

2. app/layout.tsx
   --------------
   * Objective: Define the standard HTML root structure, load custom Google Fonts (Space Grotesk & Inter), set page metadata, and wrap the children with the global Navbar and Footer.
   * Connection: Serves as the outer template for all pages in the app.
   * Logic & Implementation Steps:
     a. Initializes Google fonts and stores them in CSS variables (`--font-space-grotesk` and `--font-inter`).
     b. Exports metadata object containing page titles and descriptions.
     c. Renders the main document `<html>` and `<body>` tags.
     d. Embeds `<Navbar />`, the `{children}` router page, and `<Footer />` in vertical sequence.

3. app/page.tsx
   ------------
   * Objective: Orchestrate the rendering sequence of all completed section components on the home route.
   * Connection: Serves as the landing page entry route, importing all sections.
   * Logic & Implementation Steps:
     a. Imports all 10 completed landing page sections.
     b. Orders them exactly as requested to maintain the alternating background rhythm:
        Hero (Dark) → TrustedBy (Light) → ServicesGrid (Dark) → Comparison (Light) → ProcessTimeline (Dark) → IndustriesMarquee (Light) → Stats (Dark) → Testimonials (Light) → FeaturedRoles (Light Gray) → FAQ (White).

4. components/Navbar.tsx
   ---------------------
   * Objective: Provide an interactive navigation bar with scroll detection, mobile hamburger panel toggling, and clean branding.
   * Connection: Rendered fixed at the top of layout.tsx.
   * Logic & Implementation Steps:
     a. Sets state `scrolled` via a `window.scrollY` event listener to apply a glassmorphic background (`#0B1120/85` with backdrop-filter) once the page scroll exceeds 100px.
     b. Toggles state `mobileMenuOpen` when the hamburger icon is clicked, mounting/dismounting the mobile nav menu overlay.
     c. Employs Framer Motion's `AnimatePresence` and `<motion.div>` to slide down the mobile menu panel smoothly.

5. components/Footer.tsx
   ---------------------
   * Objective: Render structured footer links (Services, Company, Get in Touch) with copyright information and a clean brand logo.
   * Connection: Fixed at the very bottom of layout.tsx.
   * Logic & Implementation Steps:
     a. Structures links in a responsive 4-column layout (`grid-cols-1 sm:grid-cols-2 md:grid-cols-4`).
     b. Implements smooth hover transitions (`transition-colors duration-200`) on link anchors.
     c. Renders copyright info with dynamic year generation using `new Date().getFullYear()`.

6. components/Hero.tsx
   -------------------
   * Objective: Display a high-impact intro header utilizing a circuit board looping background video and smooth, staggered text entry.
   * Connection: Section 1 of page.tsx.
   * Logic & Implementation Steps:
     a. Embeds an auto-playing, muted, looping `<video>` positioned absolutely in the background (`-z-20`).
     b. Adds a black gradient overlay (`-z-10`) to ensure contrast and typography legibility.
     c. Simplifies Framer Motion animations using direct `initial` and `animate` props instead of complex nested staggers.
     d. Animates word spans (`word.text`) sequentially using the formula `delay: index * 0.15` to achieve a smooth staggered appearance.

7. components/sections/TrustedBy.tsx
   ---------------------------------
   * Objective: Display trusted partner logos in a seamless, infinitely scrolling row on a white background.
   * Connection: Section 2 of page.tsx.
   * Logic & Implementation Steps:
     a. Structures 8 SVGs (Acme, Aether, Nova, Krypton, Clarity, Apex, Quantum, Echo) into a logos list.
     b. Employs double list duplication (`[...logos, ...logos]`) inside a flex container with the `.marquee-left` class to loop seamlessly.
     c. Adds left and right gradient overlays (`bg-gradient-to-r from-white to-transparent`) at `w-24` width to soften logo entries and exits.
     d. Pauses scrolling automatically when hovering anywhere inside the section using `.marquee-parent:hover`.

8. components/sections/ServicesGrid.tsx
   ------------------------------------
   * Objective: Present staffing solutions in a 4-column responsive grid on a dark background.
   * Connection: Section 3 of page.tsx.
   * Logic & Implementation Steps:
     a. Implements a responsive grid container (`grid-cols-1 md:grid-cols-2 lg:grid-cols-4`).
     b. Renders 4 services cards (Permanent Hiring, Contract Staffing, Executive Search, Dedicated Hiring Teams).
     c. Styles cards with semi-transparent white background (`rgba(255,255,255,0.7)`), backdrop blur (`blur(16px)`), and a light border.
     d. Animates cards on hover (`whileHover`): lifts card (`y: -8`), changes border to primary blue (`#0A66F5`), and applies a blue glow shadow.
     e. Slides the CTA arrow right by `1.5` units on card hover using Tailwind's `group-hover:translate-x-1.5`.

9. components/sections/ProcessTimeline.tsx
   ---------------------------------------
   * Objective: Showcase the hiring process timeline with viewport-triggered draw animations and a traveling dot.
   * Connection: Section 5 of page.tsx.
   * Logic & Implementation Steps:
     a. Triggers draw and stagger entries once the container enters viewport using Framer Motion's `useInView`.
     b. Timeline Line: Uses inline SVGs for desktop (horizontal) and mobile (vertical). Animates the line drawing using `pathLength: 0 → 1` via `motion.line` once in view.
     c. Traveling Dot: Animates a `<motion.circle>` infinitely (`repeat: Infinity`) along the SVG coordinates (animating `cx` on desktop, `cy` on mobile).
     d. Node Animation: Staggers the entry of each timeline node (scale `0 → 1`, opacity `0 → 1`) with `0.2s` delays between steps.

10. components/sections/Comparison.tsx
    ----------------------------------
    * Objective: Highlight platform advantages by contrasting traditional staffing with SARS TALENT.
    * Connection: Section 4 of page.tsx.
    * Logic & Implementation Steps:
      a. Left Column (Traditional): Styled in muted gray text with muted red cross icons to signal drawbacks.
      b. Right Column (SARS TALENT): Encased in a highlighted dark card (`bg-[#0B1120]`) with white text and blue checkmarks.
      c. Center Divider: Renders a vertical metallic line on desktop and a horizontal line on mobile.
      d. VS Badge: Centered badge that scales (`1` to `1.08`) and pulses a blue glow shadow infinitely.

11. components/sections/IndustriesMarquee.tsx
    -----------------------------------------
    * Objective: Present industries and technology stacks in dual opposite-scrolling rows on a light background.
    * Connection: Section 6 of page.tsx.
    * Logic & Implementation Steps:
      a. Row 1 (Industries): Scrolls right-to-left using `.marquee-left`.
      b. Row 2 (Technologies): Scrolls left-to-right using `.marquee-right`.
      c. Pills: Styled in light mode glass (`bg-neutral-50 border border-neutral-200/80 text-neutral-800`).
      d. Hovering either row pauses only that row by placing `.marquee-parent` wrappers on each row individually.

12. components/sections/Stats.tsx
    -----------------------------
    * Objective: Present company metrics in a responsive grid using viewport-triggered count-up animations.
    * Connection: Section 7 of page.tsx.
    * Logic & Implementation Steps:
      a. Houses 4 stats cards: 500+, 98%, 72 Hours, and 250+.
      b. Counter Component: Uses Framer Motion's `useInView` to detect visibility (configured with `once: true` and a `margin: "-50px"`).
      c. Animation: Triggers `animate(0, value)` on visibility, updating state using `Math.floor(latest)` on each update frame to show counting.

13. components/sections/Testimonials.tsx
    ------------------------------------
    * Objective: Display client success quotes in a sliding carousel with auto-rotation.
    * Connection: Section 8 of page.tsx.
    * Logic & Implementation Steps:
      a. Tracks `currentIndex` and auto-rotates slides to the left every 5 seconds.
      b. Seamless Loop: Duplicates the testimonials list. Once transition reaches index 6, it instantly disables transition (`isTransitioning = false`) and resets `currentIndex` to 0.
      c. Center Scaling: Dynamically scales the active/center card to `1.02` and applies a blue drop shadow.
      d. Dot Indicators: Clickable pill-shaped indicators. The active slide dot is styled in blue and becomes wider.

14. components/sections/FeaturedRoles.tsx
    -------------------------------------
    * Objective: Feature open engineering job roles in a hover-interactive, fully accessible grid.
    * Connection: Section 9 of page.tsx.
    * Logic & Implementation Steps:
      a. Layout: Renders a 3-column responsive grid on a light-gray (`#F8FAFC`) background.
      b. Hover: Lift card (`y: -8`), change borders to blue, apply blue glow shadow, and slide the apply arrow.
      c. Keyboard Accessibility: Adds `tabIndex={0}` and an `onKeyDown` handler (Space/Enter to trigger click) to make card blocks accessible.

15. components/sections/FAQ.tsx
    ---------------------------
    * Objective: Answer questions in a WAI-ARIA compliant, height-expanding accordion.
    * Connection: Section 10 of page.tsx.
    * Logic & Implementation Steps:
      a. Click Toggle: Expands the selected question and collapses the others (mutual exclusion).
      b. Animation: Expands height (`0 → auto`) and opacity (`0 → 1`) smoothly using Framer Motion.
      c. Icon: SVG plus (`+`) rotates 45° to form a cross (`x`) when active.
      d. Active Styling: Adds a `3px` blue left border and a soft blue background tint.
      e. Accessibility: Programmatically links triggers to panels using `id`, `aria-expanded`, `aria-controls`, `aria-labelledby`, and `role="region"`.
